**Enterprise Power Platform & Cloud Solutions Architecture Portfolio** is an interactive, executive-level showcase presenting architectural strategies, real-world legacy system migrations (Lotus Domino ➔ Microsoft 365 / Dataverse), and technical competencies authored by **Ali Akhmad Fauzie**.

---

## 🌟 Portfolio Sections

1. **Executive Showcase**: Strategic competencies across Dataverse-first architecture, C# Plugin development, custom PCF controls, and enterprise ALM pipelines.
2. **Interactive Migration Case Studies**: Step-by-step visual breakdowns of complex enterprise migrations, showing before/after architecture, cost optimization, and risk mitigation.
3. **Interactive Power Platform Demos**: Embedded live simulations of Model-Driven apps, Canvas applications, and automated Power Automate cloud flows.
4. **Competency Matrix**: Evaluated proficiencies in Cloud Architecture, Azure Integration Services, React/TypeScript, and Security Governance.

## 🚀 Running Locally

```bash
git clone https://github.com/aliakhmadfauzie/power-platform-portfolio.git
cd power-platform-portfolio

npm install
npm run dev
npm run build
```

## 🛡️ Image Generation Compliance Rules
1. **Rule 1 (Zero Repo Reuse):** Zero images reused or copied from existing repository folders; 100% freshly rendered.
2. **Rule 2 (Platform Classification):** Explicit distinction between **Mobile Apps** (centered framed viewports) and **Desktop Apps** (multi-column OS workstation windows).
3. **Rule 3 (Anti-Marathon-Scroll):** No super-long vertical scrolling screenshots; segmented into crisp 4:3 HD sectional viewports.
4. **Rule 4 (Mandatory 5-Screen Matrix):** Every application features: (1) Login, (2) Dashboard, (3) Transaction Form, (4) Profile, and (5) Distinctive Additional Feature.

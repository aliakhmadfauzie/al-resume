**Ali Akhmad Fauzie Portfolio & Digital Resume** is an interactive portfolio and living resume engineered with React 19, Vite, and Tailwind CSS. It highlights professional software engineering achievements, cross-border architectures, full-stack enterprise solutions, and features an integrated Gemini AI conversational assistant.

---

## 🌟 Interactive Highlights

- **AI Career Concierge**: Conversational assistant grounded in professional experience, tech stack proficiency, and project outcomes powered by Google Gemini.
- **Interactive Project Showcase**: Live case studies spanning PropTech (LewiHouse), B2B Logistics (SaltDistribute), and Enterprise Manufacturing Modernization (IOI Acidchem).
- **Architecture & Competency Visualizer**: Dynamic visual representation of competencies across Mobile (React Native / Kotlin), Cloud (Firebase / GCP / Azure), and Frontend (React 19 / TypeScript).
- **Celebration Micro-Interactions**: Smooth confetti triggers (`canvas-confetti`) on contact actions and resume downloads.

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/aliakhmadfauzie/al-resume.git
cd al-resume

# Install dependencies
npm install

# Run local development server
npm run dev

# Production build
npm run build
```

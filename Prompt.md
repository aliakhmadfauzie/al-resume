# Functional Specifications & Grounding Rules (from Architectural Guideline)
1. **Two-Phase Recruiter Scanning Protocol**:
   - *Phase 1: Fast Visual Triage (6–11 Seconds)*: Satisfy the 6-second scan rule. Evaluator immediately fixates on candidate name, current/target title, employer pedigree (Accenture, Concentrix, IOI), quantifiable headline metric (\$960K saved, 365+ DBs), and frictionless resume/contact actions.
   - *Phase 2: Evaluative Deep Reading (30–60+ Seconds)*: Layer-Cake architecture using prominent descriptive headers so evaluators can selectively scan and drill into technical proof points.
2. **Defeating the F-Pattern**:
   - No dense, unformatted paragraphs.
   - Employ the **Inverted Pyramid Principle**: Front-load the first 2–3 words of every line, heading, and bullet point with high-impact action verbs and numerical anchors.
3. **Above-the-Fold Real Estate**:
   - Value Proposition Formula: $\text{Target Role} + \text{Core Competency} + \text{Quantified Impact} + \text{Unique Differentiator}$.
   - Split CTAs: High-intent primary action ("Download Executive CV") paired with low-friction secondary action ("Explore Architecture Sandbox" / "Contact").
   - Eliminate false floors via peeking proof counters or directional visual cues.
4. **Quantified Impact Framework**:
   - Every project highlight must strictly follow the **PAR / STAR / XYZ Formula** ($\text{Accomplished [X]} \text{ as measured by [Y]} \text{ by doing [Z]}$).
   - Spotted Pattern anchors: Bolded metrics, proper nouns, and currency figures (e.g., **$960K/yr**, **365+ DBs**, **7,878 screens**, **-73% CAPA time**).
5. **Frictionless Interaction & Contact**:
   - Zero-click / one-click access to resume and email/LinkedIn.
   - Streamlined contact channels with zero cognitive barriers.
